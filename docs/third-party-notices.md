# Third-party building blocks

- HeroUI 3.2.4 (`@heroui/react`, `@heroui/styles`), MIT. Used for accessible homepage interaction buttons. https://heroui.com/
- Lucide React 1.42.0, ISC. Interface icons. https://lucide.dev/
- mathjs 15.2.0, Apache-2.0. Symbolic differentiation and expression evaluation, loaded with the math lab. https://mathjs.org/
- Logisim.app by DRS Software. The external browser application is based on Logisim 2.7.2 and distributed under GPL-2.0. It is embedded on demand and not copied into this repository; its own credits, source links, and export controls remain intact. https://logisim.app/
- OneCompiler: external hosted C++ compiler retained from the supplied original simulator. https://onecompiler.com/
- OriginKit (https://originkit.dev/) and Uiverse (https://uiverse.io/) were inspected as motion and glass-surface references. No code from those sites is copied into this release. `universe.io` is not the UI library.

The ruby palette, stacked mark, floating code windows, and appearance controls originate in the supplied EduMoe designs. Product-specific surface styling is maintained in app/globals.css.
